Built on VSS

The Vehicle Signal Specification (VSS) from COVESA is an open catalog of vehicle data, not a programming framework. It names every signal a car can expose with a dot path such as Vehicle.Body.Lights.Fog.Front.IsOn and gives it a kind, a datatype, a unit, and allowed values. BMW, Volvo, JLR, Bosch, and others contribute to it, and servers such as KUKSA expose a car's live data under these names.

  • sensor is read from the car, like Vehicle.Speed. actuator can be requested, like Vehicle.Cabin.HVAC.IsAirConditioningActive. attribute is a fixed fact, like the tank capacity.
  • This tool set names every vehicle state value after its VSS signal and keeps VSS's types, units, and allowed values. Tools follow them too: fan speed is stored in percent, the sunroof can tilt, and seat heating and ventilation share one heating-cooling value, so a seat cannot heat and cool at once.
  • What VSS lacks, such as the hybrid mode, navigation stops, and media mute, is added as an overlay in VSS's own format. COVESA's vss-tools accepts the overlay in strict mode, so every path here resolves to a real or declared signal.
